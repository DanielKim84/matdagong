# 맛다공 가입 소개 시안 A–K

각 `*-flow.png`는 시안 하나당 소개 화면 5페이지를 순서대로 보여주는 완성 흐름 보드입니다. 화면 하나씩이 각각의 시안인 구성이 아닙니다.

- `A-flow.png`: 기존에 선택했던 상세형 방향을 5페이지 흐름으로 재구성
- `A-revised-flow.png`: 첨부한 A 디자인과 페이지 흐름을 유지한 수정안. 2–4페이지 문구와 신뢰 설명을 다듬고, 5페이지 공개 기록 목록은 구독자 목록으로 변경. 상단 브랜드 아이콘을 음식이 바로 연상되는 포크 심볼로 정리하고, 4페이지 지도는 실제 앱의 맛객 아바타 핀 스타일을 반영. 버튼은 1–4페이지 `다음`, 5페이지 `맛다공 시작하기`
- `A-mong9-icecream-inspired-flow.png`: A의 5페이지 흐름에 몽9아이스크림의 부드럽고 둥근 인상을 참고하되 필기체 느낌은 줄인 글꼴 방향을 적용하고, 상단 맛다공 아이콘은 현재 앱 아이콘을 반영한 이미지 생성 시안입니다. 실제 갤럭시 글꼴 파일을 적용한 화면이 아니라 시각 방향 검토용입니다.
- `A-pretendard-fork.png`–`E-spoqa-editorial.png`: 버튼 문구를 1–4페이지 `다음`, 5페이지 `맛다공 시작하기`로 바로잡고 상단 음식 아이콘을 바꿔 본 전체 5페이지 비교안. 생성 이미지의 글꼴은 실제 가족별 차이가 거의 없어 별도의 실제 글꼴 비교표를 추가
- `font-options-distinct.png`: Pretendard, 나눔스퀘어라운드, 주아, 개구, 블랙한산스, 도현, 나눔손글씨 펜을 실제 폰트 파일로 렌더링한 비교표. 본문은 기본 글꼴을 유지하고 제목체만 바꾸는 조합도 포함
- `font-options-handwritten.png`: 사용자가 예시로 든 몽9 계열처럼 둥글고 손으로 쓴 느낌에 가까운 개구·하이멜로디·싱글데이·감자꽃과, 비교용 둥근 글꼴 2종을 동일 문구로 렌더링한 추가 비교표. 첨부 예시의 폰트 파일을 복제한 것이 아니라 실제 글꼴 분위기를 비교하기 위한 시안
- `font-options-galaxy-reference.png`: 사용자가 공유한 갤럭시 폰트 샘플 5종을 참고해 동일한 맛다공 인트로 첫 화면을 비교한 이미지 생성 시안. 폰트 파일을 실제 적용한 결과가 아니므로 글꼴 선택 전 시각 참고용
- `B-flow.png`: 취향을 고르고 입맛에 맞는 맛객과 추천 이유를 찾는 흐름
- `C-flow.png`: 방문 확인, 추천 이유, 나의 경험 기록으로 신뢰가 쌓이는 흐름
- `D-flow.png`: 지도에서 주변 기록과 필터를 살펴 빠르게 장소를 고르는 흐름
- `E-flow.png`: 기록 공개 범위와 구독 기반 수익화 방향을 설명하는 흐름
- `F-flow.png`: 맛객 발견부터 내 지도와 공개 기록까지 이어지는 서비스 전체 흐름
- `G-flow.png`–`K-flow.png`: A의 핵심 문구·메시지 순서를 유지하고 F에 가까운 사진과 실제 앱 UI 스타일로 변형한 추가안 5종

상위 폴더의 [인트로 전체 흐름 시안 갤러리](../intro-directions.html), [상단 아이콘 비교 갤러리](../intro-font-icon-options.html), [실제 글꼴 비교표](../intro-typography-options.html)에서 큰 화면으로 볼 수 있습니다. 각 전체 흐름 보드는 기획 검토용 시안이며, 화면 안의 인물·가게·수치는 예시입니다. A 수정안은 상단 브랜드 아이콘을 유지하고, 지도 마커에만 실제 앱 코드의 맛객 아바타 핀(관계별 색상)을 반영했습니다. 새 비교안은 1–4페이지 버튼이 `다음`, 5페이지 버튼이 `맛다공 시작하기`입니다. 실제 앱에 적용할 글꼴은 별도 확정이 필요합니다. 특히 E·K와 A 수정안의 수익화 표현은 방향 시안이며 현재 유료 구독이나 정산 기능의 운영을 의미하지 않습니다.

이전에 생성한 한 장짜리 탐색 이미지는 `single-page-explorations/`에 보관했습니다. 이는 전체 페이지 흐름 시안과 구분하기 위한 참고 자료입니다.
