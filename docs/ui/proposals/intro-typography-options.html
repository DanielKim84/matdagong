원하신 손글씨 느낌으로 다시 비교

보내주신 몽9 글꼴처럼 둥글고 손으로 쓴 인상이 나도록, 같은 인트로 문구를 실제 글꼴 파일로 렌더링했습니다. 제목 글꼴만 바꾸고 본문과 버튼은 읽기 쉬운 기본 글꼴로 두었습니다.

A–D는 손글씨 성격이 강한 후보이고, E는 단정한 둥근 글꼴, F는 굵고 통통한 제목 글꼴입니다. 첨부해주신 몽9 글꼴 파일을 적용한 것은 아니며, 분위기를 비교하기 위한 실제 글꼴 시안입니다. 전체 본문까지 손글씨로 바꾸면 긴 설명의 읽기성이 낮아질 수 있어 제목만 포인트로 적용하는 방향으로 만들었습니다.
