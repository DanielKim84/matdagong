# 현재 UI 기준

맛다공은 모바일 중심으로 설계하고, 넓은 화면에서도 앱 화면 폭을 유지합니다. 화면은 `frontend/src/screens/`에, 공통 인터랙션과 그림은 `frontend/src/components/`에 둡니다. 색상과 공통 레이아웃은 `frontend/src/styles/`에서 관리합니다.

## 제품 흐름

서비스의 중심은 별점 목록을 늘리는 것이 아니라, 실제로 다녀온 맛객의 기록을 보고 내 입맛에 맞는 사람을 구독해 음식 선택의 고민을 줄이는 것입니다. 주요 흐름은 다음과 같습니다.

1. 발견(지도)과 피드에서 맛집 및 맛객의 기록을 둘러봅니다.
2. 장소 상세에서 맛객별 추천 이유와 메뉴·방문 정보를 살펴봅니다.
3. 취향이 맞는 맛객을 구독하고, 구독한 맛객의 기록을 이어서 확인합니다.
4. 맛객은 본인의 분야·활동 지역·기록을 공개 프로필로 소개합니다.

맛객 프로필의 공개 스타일과 사용자의 비공개 추천 취향은 서로 다른 설정입니다. 발견 지도와 목록에는 광고 장소를 보여 주지 않습니다.

## 시각 요소 (2026-10-30 리뉴얼 기준)

- 바탕과 색은 리뉴얼 전과 같은 밝은 웜 톤입니다. 크림 바탕 위에 흰 카드, 주요 버튼·선택 상태는 코랄, 선택한 칩은 먹색입니다. 제목은 Jua, 본문은 Pretendard입니다. 어두운(다크) 분위기는 쓰지 않습니다.
- 정보 구조는 지도 중심입니다. 하단에 떠 있는 탭 막대(발견 · 피드 · 가운데 기록 버튼 · 맛객 · 나)를 두고, 가운데 버튼은 "맛집 기록하기 / 빠른 저장" 메뉴를 엽니다.
- 발견: 지도가 화면 전체를 채우고, 위에 검색창·알림 버튼·필터 칩, 아래에 가로로 넘기는 장소 카드와 끌어 올리는 목록 시트(접힘·중간·펼침)가 있습니다. 카드를 넘기면 지도 핀이 강조되고, 핀을 누르면 해당 카드로 넘어갑니다. AI 추천 칩은 `VITE_FEATURE_AI_PICK=true`일 때만 보입니다.
- 맛집 상세: 큰 사진(없으면 위치 지도) → 장소 정보 → 빠른 동작(길찾기·저장·전화·기록하기) → 맛객 요약 → 기록/메뉴/정보 탭. 맛객 기록은 가로로 넘기는 카드이고, 아래에 저장·내 기록 버튼을 고정합니다.
- 피드: 구독한 맛객 스토리 줄 → 구독 중/전체 전환 → 기록 카드(최신순). 스토리는 전체 화면으로 넘겨 봅니다.
- 기록하기: 장소 → 사진·메뉴 → 취향 태그·방문 조건 → 추천 이유·공개 범위 → 확인의 단계형 흐름과 완료 화면입니다.
- 맛객: 탐색(추천·구독 중·나를 구독), 프로필(취향 일치율 막대, 맛집 지도·기록 목록·취향 탭), 구독 관리.
- 나: 다이어리 카드와 벤토 타일(저장한 맛집, 포인트, 구독 등), 기록 일기 달력, 모음, 지갑, 계정 설정(카카오 연결, 네이버·Apple 준비 중).
- 넓은 화면(700px 이상)에서는 앱이 둥근 틀 안에 그려지고, 하단 탭과 하단 버튼 줄도 그 틀 바닥에 붙습니다. 가로 목록은 PC에서 마우스로 조금만 끌어도 다음 카드로 부드럽게 넘어갑니다.
- 색과 제목 글꼴은 테마 패키지(`frontend/src/theme`)에서 정하며, 시즌 테마로 기간을 정해 바꿨다가 자동 복원할 수 있습니다. 방법은 [테마 관리](theming.md)를 참고합니다.
- 기본 아바타는 계정별로 배정한 맛다공 캐릭터를 사용합니다.
