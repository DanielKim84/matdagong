# 맛다공 브랜드 A

2026-11-17 확정한 현재 브랜드입니다. 열린 원형 접시와 분리된 대각선 포크가 같은 코랄을 사용합니다. 앱 아이콘과 대표 로고는 쨍한 색상·광택·입체감이 있는 형태로, 작은 심볼은 같은 구조의 평면형으로 사용합니다. 기존 물방울 마커 아이콘과 L1 로고, 비교 시안은 폐기했습니다.

## 사용 규칙

[브랜드 사용 가이드](brand-identity.png)는 로고·평면 심볼·반전형·색상·보호 여백을 정리한 기준 이미지입니다. 캐릭터·굿즈 소개판인 `brand-guide.png`와 용도가 다르므로 둘 다 유지합니다. 사용 가이드의 평면형과 대표 아이콘의 입체형은 같은 A안의 용도별 표현입니다.

- 기준 색상은 코랄 `#EF365B`, 차콜 `#20252B`, 흰색 `#FFFFFF`입니다. 입체형은 코랄의 밝은 하이라이트와 진한 음영을 사용합니다.
- 심볼은 원과 포크가 분리된 구조이며, 원 아래쪽이 열려 있습니다. 마커 형태로 바꾸거나 두 요소를 연결하지 않습니다.
- 주변 여백은 심볼 선 두께 이상 확보하고 전체 비율을 유지합니다. 워드마크·심볼 간격과 포크 각도를 임의로 바꾸지 않습니다.
- 큰 대표 이미지·아이콘에는 입체형, 작은 표시에는 평면형을 사용합니다. 코랄 배경에서는 흰색 반전형으로 대비를 확보합니다.
- 실제 이미지로 사용할 때는 소개판을 잘라 쓰지 않고 개별 파일을 사용합니다. 코드에서는 `/assets/brand/` 아래 정식 파일명을 참조합니다.
- 외부 개발자 콘솔에는 `app-icon-upload.png`를 사용합니다. 다시 내보낸 후에도 250,000바이트 이하인지 확인합니다. 외부 콘솔 등록은 별도 작업입니다.

## 브랜드와 캐릭터의 관계

다공은 상위 회사·공통 계정 브랜드이며 `dagong-auth/frontend/public/assets/brand/`의 D안을 사용합니다. 맛다공 A와 혼용하지 않습니다. 셰프와 여행자 캐릭터는 기존의 포근한 형태를 유지합니다. 소개판 속 여다공 원형 비행기 아이콘·로고는 가족 브랜드 확장 예시이며, 여다공 서비스 적용을 완료했다는 뜻은 아닙니다.

대표 소개판은 `brand-guide.png` 한 장만 관리합니다. 캐릭터 표정과 실제 봉제인형 느낌의 정면·뒷모습·키링 예시는 이 소개판에 포함합니다. 기존 셰프 시트의 포즈와 앱 내 참조는 유지했습니다.

## 적용 상태와 후속 디자인

현재 브라우저 탭·앱 시작 화면은 정식 파일명을 통해 새 아이콘을 읽습니다(시작 화면은 보드 02-01대로 `app-icon.png` 아래 "맛다공" 글자를 둔 세로 배치). 공통 로그인(dagong-auth)의 오류·다른 기기 확인 화면은 `app-icon-upload.png` 복사본(`matdagong-symbol.png`)으로 같은 세로 로고를 씁니다. 공통 로그인 흐름·토큰·보안 설정은 변경하지 않았습니다.

전체 앱 UI 재설계는 브랜드 A를 기준으로 단계적으로 적용 중입니다. 현재 기본 테마, 사진 중심 발견 첫 화면, 균등 하단 탭, 나 탭 사진 모음, 맛집 상세 정보 패널을 1차 반영했습니다. 나머지 화면은 같은 토큰과 컴포넌트 원칙을 이어 적용합니다.

이미지 생성 도구로 선택한 A의 형태와 입체감을 기준으로 아이콘·가로 로고·배너·소개판을 제작했습니다. 파일은 래스터 PNG이며 인쇄용 정밀 벡터 원본은 포함하지 않습니다.
