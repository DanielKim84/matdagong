# 포인트 원장 기준

맛다공에는 지금 포인트 기능이 없습니다. 적립·사용 처리 없이 조회만 있던 커뮤니티 `user_point_history` 원장(행 0개)과 `GET /api/v1/points`는 2026-11-25에 지웠습니다(커뮤니티 V46). 포인트 지갑 화면(`#wallet`, 보드 16-04)은 나중에 포인트가 생긴다는 것을 보여 주려고 남겨 두었고, 서버를 부르지 않고 잔액 0P와 "준비 중" 안내만 보여 줍니다.

포인트는 맛다공·여다공이 함께 쓰도록 **다공 공통 포인트 서버**(`dagong-point`, 포트 4841 예정)로 따로 만듭니다. 공통 로그인(`dagong-auth`)처럼 계정 UUID로 연결하고, 맛다공 서버는 업무 이벤트(구독 완료 등)를 알려 주기만 합니다.

새로 만들 때 지킬 원칙입니다.

- 잔액은 적립·사용·조정 거래의 합계입니다. 기존 거래를 덮어쓰거나 삭제해 잔액을 맞추지 않고, 상계 거래를 추가합니다.
- 지급·사용·환불은 서버가 정책과 완료된 업무 이벤트를 확인한 뒤에만 원장 행을 추가합니다. 화면이 보낸 금액을 믿지 않습니다.

정산이나 교환을 출시하기 전에는 최소한 다음을 정해야 합니다.

- 어떤 이벤트에 얼마를 적립할지, 취소·환불 시 어떻게 상계할지
- 중복 요청을 막을 멱등성 키와 원장 참조 규칙
- 잔액 부족·동시 사용을 막는 트랜잭션 처리
- 관리자 조정 권한과 사유 기록, 감사 이력
- 상품권·현금 교환을 포함한 사업 및 규제 검토
