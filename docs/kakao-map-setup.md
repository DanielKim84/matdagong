# 카카오 지도 연결하기

## 1. 카카오 개발자 앱 설정

1. [Kakao Developers](https://developers.kakao.com/)에서 맛다공용 앱을 선택하거나 새로 만듭니다.
2. 앱의 **앱 키** 메뉴에서 **JavaScript 키**를 복사합니다. REST API 키나 네이티브 앱 키가 아닙니다.
3. **카카오맵 > 사용 설정**을 켭니다. 무료 쿼터를 사용할 계획이면 계정에서 첫 번째로 지도 API를 활성화하는 앱인지 확인하고, 앱 정보에 무료 쿼터 배지가 있는지 확인합니다.
4. **플랫폼 > Web**에 로컬 개발 도메인을 등록합니다.

```text
http://localhost:4845
```

출시할 때는 실제 서비스 도메인도 같은 앱의 Web 플랫폼 설정에 추가합니다. 키를 외부에 공개해도 된다는 뜻은 아니므로, 저장소에 키를 커밋하지 말고 등록된 도메인에서만 쓸 수 있게 제한합니다.

## 2. 로컬 키 입력

`frontend/.env.example`을 복사해 `frontend/.env.local` 파일을 만들고 JavaScript 키를 입력합니다.

```dotenv
VITE_KAKAO_MAP_APP_KEY=발급받은_JavaScript_키
```

Vite는 환경 변수를 시작 시 읽으므로 파일을 만든 뒤 프런트엔드 개발 서버를 다시 시작합니다.

```powershell
cd frontend
npm.cmd run dev
```

`.env.local`은 Git에서 제외됩니다. 브라우저에 전달되는 JavaScript 키는 비밀 키가 아니므로, 보호의 핵심은 키를 코드 저장소에 숨기는 것이 아니라 Kakao Developers에서 허용 도메인을 정확히 등록하는 것입니다.

## 현재 연동 범위

- Kakao Maps JavaScript SDK를 지도 전용 컴포넌트에서 불러옵니다.
- matdagong-place-service가 반환한 위도·경도를 마커 위치로 사용합니다.
- 마커를 누르면 기존 장소 상세 API/팝업 흐름을 사용합니다.
- `내 위치` 버튼을 누를 때 브라우저 위치 권한을 요청하고 지도를 해당 좌표로 이동합니다. 현재 위치는 파란 점으로 표시합니다.
- SDK 키가 아직 없으면 안내 문구를 보여주며, 앱의 다른 탭은 계속 사용할 수 있습니다.
- 사용자 좌표 추적은 사용자가 버튼을 눌러 한 번 위치를 가져오는 방식입니다. 백그라운드/실시간 추적은 구현하지 않았습니다.

주변 영역을 이동할 때 서버에서 해당 지도 영역의 장소만 다시 조회하는 기능은 현재 백엔드 API가 전체 샘플 목록만 반환하므로 아직 연결되지 않았습니다. 그 기능을 만들 때는 지도 경계 좌표를 matdagong-place-service에 전달하는 검색 API를 추가하면 됩니다.
