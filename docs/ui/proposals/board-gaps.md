## 기능 단계에서 정리할 것 (디자인을 보드대로 맞추며 화면에서 뺀 기능)

디자인 단계에서는 보드에 없는 버튼만 화면에서 뺐고, 그 뒤에 남은 서버·호출 정리는 기능 단계에서 함께 결정합니다.

- 알림(07-03): 알림 하나 지우기 · 모두 읽음 · 모두 삭제 버튼을 뺐습니다. `services/community.ts`의 `deleteNotification`·`markAllNotificationsRead`·`deleteAllNotifications`와 서버 API를 남길지 정합니다.
- 가게 정보 제보(10-04): "전화" 항목을 화면에서 뺐습니다. 장소 모듈 `PlaceReportReason.WRONG_PHONE`과 DB 값 정리를 정합니다.
- 발견 필터(05-03): "내 위치에서 보기" 반경 고르기를 뺐습니다(지도는 늘 500m로 시작).
- 맛집 상세(09): 기록 아래 버튼 줄 대신 ⋯ 메뉴로 옮겼고, 맛객 목록 시트를 없앴습니다. 길찾기가 아래 고정 줄과 위치 칸 두 곳에 있습니다(보드대로). 같은 문제가 다시 보이면 백업 구성으로 되돌립니다.
- 기록하기 3단계(11-03): 장소 분야(음식점·카페) 고르기와 태그·정보 제안 버튼을 뺐습니다(분야는 가게 분류로 정함).
- 내 맛집 모음(13): 여러 곳을 골라 한 번에 공유 범위를 바꾸던 기능을 줄마다 고르는 방식으로 바꿨습니다.
- 구독 선택(16-03): 유료 구독을 "준비 중"으로 막았습니다. 쓰지 않던 구독 상품 API(`GET /subscriptions/plans`)는 2026-11-25에 지웠고, 유료 구독 기간 검증(1·3·6·12개월)만 남았습니다. 요금은 결제를 붙일 때 정합니다.
- 맛객 탭(08-01): "내가 구독한 맛객" 가로 줄 · 맛객 둘러보기 섹션 · 지역 묶음 구독(준비 중) 안내를 없앴습니다. 맛객 프로필(08-04)의 맛집 지도를 없앴습니다.
- 서버가 주지 않아 아직 비워 둔 칸: 영업시간·휴무·좌석(09-01), 최근 본 시각과 날짜 띠(14-02), 맛객별 가볼 곳 수(04-04), 카카오 가게 사진(11-01·06-04).
- 프로필 편집(15): 보드에 없는 분야 고르기(식당·카페·둘 다)와 "추천 취향에서 가져오기"는 기능을 지키려고 작은 칩 줄·알약으로 남겼습니다. 활동 범위(지역 중심·여행·드라이브·둘 다)도 지역 칩 아래 작은 칩으로 남겼습니다. 지역 칩은 보드처럼 × 없이 누르면 빠지고 (i)에서 알려 줍니다. 배경 사진 첫 장의 ×는 대표 사진도 지울 수 있게 남겼습니다. 소개는 서버 한도대로 300자입니다(보드 60자).
- 태그 제안(17-04): 설명은 서버가 300자까지 받지만 화면은 보드대로 100자까지만 받습니다. "적용 예정" 상태는 서버에 없어 검토 중 · 적용 완료 · 미반영 세 가지입니다.
