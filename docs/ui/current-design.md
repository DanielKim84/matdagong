# 현재 UI 기준

맛다공은 모바일 중심으로 설계하고, 넓은 화면에서도 앱 화면 폭을 유지합니다. 화면은 `frontend/src/screens/`에, 공통 인터랙션과 그림은 `frontend/src/components/`에 둡니다. 색상과 공통 레이아웃은 `frontend/src/styles/`에서 관리합니다.

## 제품 흐름

서비스의 중심은 별점 목록을 늘리는 것이 아니라, 실제로 다녀온 맛객의 기록을 보고 내 입맛에 맞는 사람을 구독해 음식 선택의 고민을 줄이는 것입니다. 주요 흐름은 다음과 같습니다.

1. 홈과 지도에서 맛집 및 맛객의 기록을 둘러봅니다.
2. 장소 상세에서 맛객별 추천 이유와 메뉴·방문 정보를 살펴봅니다.
3. 취향이 맞는 맛객을 구독하고, 구독한 맛객의 기록을 이어서 확인합니다.
4. 맛객은 본인의 분야·활동 지역·기록을 공개 프로필로 소개합니다.

광고 맛집은 맛객의 기록과 구분해 광고로 표시합니다. 맛객 프로필의 공개 스타일과 사용자의 비공개 추천 취향은 서로 다른 설정입니다.

## 시각 요소

- 서비스 소개 화면은 밝은 크림 바탕과 코랄 포인트를 쓰고, 지도 일러스트만 옅은 하늘색으로 구분합니다.
- 지도 마커는 구독, 다른 맛객, 취향 일치, 내 기록, 광고를 구분하고, 맛객 사진이 있으면 캐릭터 대신 사진을 사용합니다.
- 기본 아바타는 계정별로 배정한 맛다공 캐릭터를 사용합니다.
- 서비스 소개는 맛객의 실제 경험 → 장소와 취향 발견 → 맛객 구독 → 기록 공유의 가치를 순서대로 전달합니다.

## 확인 경로

- 앱: `http://localhost:4845/`
- 소개: `http://localhost:4845/#intro`
- 지도: `http://localhost:4845/#map`
- 맛다공 공통 로그인: `http://localhost:4840/login`

지도는 Kakao Maps SDK를 사용합니다. 장소 정보는 현재 샘플 카탈로그에서 제공하며 실제 장소 DB와 사진 저장소는 아직 연결하지 않았습니다.
