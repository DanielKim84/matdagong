# 맛다공 서비스 소개 시안 (H안)

앱 서비스 소개(`IntroScreen`)는 H안으로 정했습니다(2026-11-24). 이 폴더에는 정한 안만 남깁니다. 비교했던 A–K안과 글꼴·아이콘 비교 그림은 저장소에 올리지 않았습니다.

- `H-flow.png`: H안 원본 보드. 소개 5쪽을 순서대로 보여 주는 한 장짜리 흐름입니다.
- `H-flow-applied.png`: 앱에 적용한 기준 그림. 원본에서 쪽 표시(1/5)를 지우고, 1쪽 왼쪽 위 입체 맛다공 로고, 2쪽부터 뒤로 버튼, 쨍한 코랄 버튼(1쪽 건너뛰기 · 다음, 2~4쪽 다음, 5쪽 맛다공 시작하기)만 바꿨습니다. 사진·배경·카드는 원본 그대로입니다.

화면 안의 인물·가게·수치는 예시입니다. 수익화 표현은 방향 시안이며 유료 구독·정산 기능의 운영을 뜻하지 않습니다.
