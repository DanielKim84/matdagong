# 보드 시안 이미지 자산

이 폴더에는 `../`의 화면 보드에서 반복 사용하는 음식·맛객·매장·지도 예시 이미지를 모았습니다. 앱 배포용 확정 자산이 아니라 기획 및 UI 시안 검토용 샘플입니다. 인물과 가게는 생성된 예시이며 실제 인물·업체를 나타내지 않습니다.

## 프로필·매장·지도

- `taster-woman.jpg`, `taster-man.jpg`: 맛객 프로필 예시
- `restaurant-interior.jpg`: 매장 사진 및 프로필 추천 장소 썸네일
- `map-preview.svg`: 발견 지도·상세 위치 패널의 지도 배경 예시

## 출처 및 사용

음식 사진, 인물, 매장 사진은 이 UI 시안을 위해 생성했습니다. 파일명은 시안 제작 편의를 위한 식별자입니다. 지도 SVG도 시각 예시이며 실제 주소·도로 데이터를 나타내지 않습니다.
